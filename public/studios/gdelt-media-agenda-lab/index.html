Why This Makes A Good Classroom Lab

Students can move from a raw keyword to a defensible claim about media attention.

1. Attention is normalized, not just counted

DOC timeline volume reports coverage as a percent of the global monitored news stream, which makes time comparisons less naive than raw article counts.

2. Tone should be treated as a distribution

The GDELT docs emphasize tone histograms because a single average can hide whether coverage is actually clustered, neutral, or polarized.

3. TV comparisons need airtime normalization

The TV API recommends normalized clip percentages for comparing stations and periods, since monitored airtime and programming mix differ across stations.

API Query Pattern

The page builds URLs from the current query and lens, then queues requests at least five seconds apart.

Interpretation Caveat Media attention is not public opinion
GDELT measures what monitored media says, where, when, and with what machine-coded tone. It should be interpreted as a media agenda signal, not a survey of what people believe.
Sources

The GDELT Project, DOC 2.0 API documentation, and TV 2.0 API documentation. The newer GDELT Cloud v2 API is cleaner for structured event dashboards but requires an API key, so this public gallery page uses the no-key public APIs.

Live API Behavior

The public endpoint can return empty responses or rate-limit bursts. This page makes requests sequentially, caches live results per query, and labels synthetic demo data whenever it is shown.
